# موقع رواد الشهادة

مكتبة عربية متجاوبة تضم الكتب والامتحانات والمذكرات المتاحة في مجلد Google Drive العام. يحتوي `catalog.json` على لقطة الفهرس التي جرى جمعها في 25 نوفمبر 2026: 324 ملفًا و55 مجلدًا. الفهرس ليس مزامنة مباشرة.

## التشغيل محليًا

شغّل خادم ملفات HTTP من مجلد الموقع:

```bash
python3 -m http.server 3000
```

ثم افتح `http://localhost:3000`. لا تفتح `index.html` مباشرة لأن المتصفح يحتاج إلى تحميل `catalog.json` عبر HTTP.

## رفع الموقع إلى GitHub Pages

1. فك ضغط ملف ZIP على الهاتف أو الحاسوب.
2. ارفع **محتويات المجلد المستخرَج** إلى جذر مستودع GitHub، بحيث يظهر `index.html` في الصفحة الرئيسية للمستودع. رفع ZIP وحده لا يجعل GitHub Pages يفكّه ويشغّله.
3. في المستودع افتح **Settings → Pages**، واختر **Deploy from a branch** ثم الفرع `main` والمجلد `/(root)`، واضغط **Save**.
4. بعد اكتمال النشر افتح الرابط الذي يعرضه GitHub Pages. جميع ملفات الموقع مرتبطة بمسارات نسبية لتعمل سواء نُشر الموقع في جذر النطاق أو في مسار المستودع.

## الفهرس والقراءة

زر «اقرأ الآن» يفتح معاينة Google Drive داخل الموقع، ويوفر رابطًا بديلًا إلى Drive. قد تمنع إعدادات المشاركة معاينة ملف بعينه؛ الموقع لا يغيّر صلاحيات الملفات الأصلية ولا ينسخها. ظهر مجلد «القرآن الكريم كاملاً» في الفهرس العام لكنه لم يعرض ملفات داخله وقت الجرد.

لتحديث المكتبة، يلزم إعادة جرد مجلد Drive العام واستبدال `catalog.json` بالبيانات الجديدة. لا توجد لوحة إدارة أو مزامنة تلقائية.
